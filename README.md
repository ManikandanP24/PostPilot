# PostPilot

Create once. Publish everywhere. PostPilot is a Next.js App Router application for preparing, previewing, scheduling and tracking posts for Instagram, Facebook Pages and LinkedIn from one workspace.

See `RENDER_DEPLOY.md` for Render Blueprint deployment, and `supabase/schema.sql` for database setup. Copy `.env.example` to `.env.local` for local development. See the full setup guide in the repository README after the source upload finishes.
